은행 로고 이미지 폴더
=====================

여기에 아래 파일명으로 은행 로고 이미지를 넣으면, 사이트에서 은행명 옆에
색상 뱃지 대신 실제 로고가 표시됩니다. 파일이 없으면 자동으로 기존 색상
뱃지(신한·KB·카카오 등)로 대체되므로, 있는 것만 넣어도 됩니다.

권장 사양
- 형식: PNG(투명 배경 권장) 또는 SVG(SVG로 쓰려면 main.js의 BANK_BRAND
  logo 값 확장자를 .svg로 바꾸세요)
- 크기: 정사각형 권장(예: 64x64 ~ 128x128). 표시 크기는 22x22로 축소됨.

파일명 매핑 (main.js의 BANK_BRAND 기준)
- 신한은행        → shinhan.png
- 국민/ KB국민은행 → kb.png
- 우리은행        → woori.png
- 하나은행        → hana.png
- 농협/ NH농협은행 → nh.png
- IBK기업은행     → ibk.png
- 카카오뱅크      → kakaobank.png
- 토스뱅크        → tossbank.png
- 케이뱅크        → kbank.png
- SC제일은행      → sc.png
- 부산은행        → busan.png
- 대구은행        → daegu.png
- 경남은행        → gyeongnam.png
- 광주은행        → gwangju.png
- 전북은행        → jeonbuk.png
- 제주은행        → jeju.png

※ 은행 로고는 각 은행의 상표/저작물입니다. 데모·학습 용도 범위에서
   사용하시고, 배포·상업적 사용 시에는 각 은행의 사용 정책을 확인하세요.
