# 시연영상 자동 녹화

Playwright가 사이트를 조작하면서 화면을 녹화한다. OS 커서는 영상에 찍히지 않으므로, 페이지에 **가짜 커서(클릭 효과 포함)와 자막을 주입**해 녹화하면서 같이 찍는다. 후편집은 하지 않는다. 결과물은 1440×900 H.264 mp4, 무음이다.

2026-10-27 첫 녹화본: `~/Desktop/매치뱅크_시연.mp4`(7분 25초).

## 파일

| 파일 | 역할 |
|---|---|
| `captions.json` | 장면별 자막. `1`~`28`은 본편, `M1`~`M7`은 마이페이지. **문구만 바꿀 때는 이 파일만 고친다.** |
| `record.js` | 장면 시나리오. 세그먼트 3개로 나뉜다(아래). |
| `lib.js` | 공용 도우미: 커서·자막 주입, 이동·클릭·타이핑, 부드러운 스크롤. |
| `setup.sh` / `build.sh` | 설치 / mp4 변환과 이어 붙이기 |

세그먼트는 따로 찍어 이어 붙인다. 고칠 부분만 다시 찍으면 된다.
- **A** (약 2분 15초): 비로그인 홈 → 히어로 버튼 → AI은행원(추천 칩 → 적금 추천 → 👎 피드백 제출) → 이체 요청 → 로그인 → 확인 카드 → PIN → 이체 완료
- **B** (약 3분 25초): demo 계정 → 내 계좌(거래내역, 김철수 3만원 이체 → 영수증) → 상품안내(인기 통계, 5개 탭, 국민·우리·토스뱅크 사이트) → 고객센터 → 마이페이지 → 로그아웃
- **C** (약 1분 45초): admin 로그인 → 백오피스 9개 메뉴

## 순서

```bash
cd demo
./setup.sh                          # 처음 한 번(이 폴더 안에만 설치)
```

1. **서비스 확인:** 백엔드 :8000, 챗봇 :8501, 이체 워커, Kafka·ES·Redis·Phoenix가 모두 떠 있어야 한다. 백오피스 상태가 **4/4 정상**인지 본다(`/api/admin/infra-metrics`). 워커가 없으면 이체가 `pending`에서 멈춘다.
2. **DB 백업:** A·B가 실제 이체(5만원, 3만원)와 피드백을 남긴다. 녹화 전 `bank.db`를 백업하고 대화 목록도 기록해 둔다.
   ```bash
   cp ../bank.db /tmp/bank.db.before-demo && ls ../conversations > /tmp/conv.before-demo.txt
   ```
3. **녹화:** 반드시 **A → B 순서**로 찍는다. B의 거래내역에 A의 이체가 나와야 한다. C는 따로 찍어도 된다.
   ```bash
   npm run record:A && npm run record:B && npm run record:C
   ```
   진행 로그(`[초] caption N`)가 stderr로 나온다. 멈춘 동작이 있으면 `TIMEOUT`, `ERR`가 찍힌다. 실패하면 `out/fail-<세그먼트>.png`에 그때 화면이 남는다.
4. **이어 붙이기:** `./build.sh`. 세그먼트별 가장 최근 녹화를 쓰고, 기본 출력은 `~/Desktop/매치뱅크_시연.mp4`다.
5. **원상복구:** `bank.db`를 백업으로 되돌리고, 녹화 중 새로 생긴 `conversations/*.json`을 지운다(2에서 기록한 목록과 비교).

한 세그먼트만 다시 찍을 때도 그 세그먼트가 바꾸는 데이터를 고려한다. 예를 들어 B를 다시 찍으려면 DB를 "A 직후" 상태로 맞춰야 거래내역이 같게 나온다. 가장 간단한 방법은 녹화 전 DB로 되돌리고 A·B를 함께 다시 찍는 것이다.

## 알아 둔 함정

- **스크롤은 타이머로 움직인다.** `requestAnimationFrame` 기반이던 첫 버전이 헤드리스에서 멈춰, 영상이 2시간짜리가 됐다. `page.evaluate`에는 자체 타임아웃이 없어서 `withTimeout`(20초)으로 감싼다.
- **AI은행원 화면은 자막을 위쪽에 띄운다**(`d.setCaptionTop(true)`). 아래쪽 자막이 입력창을 가려 질문 타이핑이 안 보였다.
- **AI 답변 완료 신호는 👍 버튼 개수 증가다**(`waitAnswer`). 답변 시간이 매번 달라서 고정 대기 대신 이 신호를 쓴다.
- **로그인 후 AI가 이체 요청을 자동으로 이어 가지 않는다.** 확인 카드가 없으면 같은 문장을 다시 보낸다(영상에 두 번 나온다).
- **새 탭은 영상에 안 담긴다.** 은행 바로가기는 녹화 중에만 `target=_self`로 바꿔 같은 탭에서 열고 뒤로 돌아온다. AI 답변의 "홈페이지에서 검색하기"는 커서로 강조만 한다.
- **Streamlit 체크박스는 라벨 텍스트를 클릭한다.** `<input>`을 직접 누르면 오버레이가 가로챈다.
- 홈 히어로 왼쪽의 흐릿한 원은 원래 디자인(three.js)이다. 일반 브라우저에서도 같다.
